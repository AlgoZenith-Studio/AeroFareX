# NASA DC-8 aircraft model

- Source: [NASA Airborne Science Program 3D Models Gallery](https://airbornescience.nasa.gov/content/3D_Models_Gallery)
- Original file: `DC8_AFRC_AIR_0824.glb`
- Source URL: https://airbornescience.nasa.gov/sites/default/files/pages/DC8_AFRC_AIR_0824.glb
- Model used in this site: `nasa-dc8.glb`
- Change: The original GLB was optimized with glTF Transform 4.5.0. Geometry was quantized. Textures were resized to a maximum of 2048 pixels and encoded as WebP. The file size changed from 14.5 MB to 1.81 MB. The aircraft shape and livery were not intentionally changed.
